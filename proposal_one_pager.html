1. Executive Summary & Problem Need

Traditional attendance tracking in lecture halls and laboratories relies on manual paper sign-in sheets. This legacy approach consumes 10–15 minutes of instructional time, invites proxy attendance, and requires tedious manual re-encoding into university grading sheets. Commercial biometric or cloud attendance units require continuous internet connectivity, high hardware procurement costs, and recurring software licensing fees that fail during campus network outages.

This proposal presents a portable, standalone, infrastructure-independent RFID Attendance Terminal powered by an ESP32 microcontroller. The unit broadcasts its own dedicated local Wi-Fi hotspot with an automatic DNS captive portal. Instructors connect using any smartphone or PC without installing apps, synchronize device time with one click, monitor live taps in real time, and export audit-ready CSV records immediately.

2. Core Objectives & Key Innovations
• 100% Standalone Offline Operation: Embedded web server, DNS engine, and NVS database run in internal flash—completely immune to external internet or cloud failure.
• Zero Hardware RTC Dependency: Eliminates RTC coin-cell battery failure by synchronizing the system clock with the connecting instructor's phone browser in 1 click during session setup.
• Single-Row Anti-Duplicate Integrity: Firmware algorithm strictly enforces "Repeated Cards Listed as ONE"—recording IN and OUT timestamps per person without duplicate roster rows.
• Boosted 48 dB RF Sensitivity: Custom antenna register configuration ensures instant card reads through the 2.5 mm solid top deck without physical contact.
• Instant Universal CSV Export: Direct browser file generation allows immediate download of attendance records formatted for Excel, Google Sheets, and institutional grading portals.
3. System Architecture & Precision Engineering
A. Embedded Electronics
• MCU: ESP32 Dual-Core 240MHz (4MB Flash)
• RFID: MFRC522 (13.56MHz SPI, Boosted 48dB)
• Display: 1602 HD44780 LCD via I2C PCF8574
• Hotspot: 802.11 b/g/n (8 Clients, 192.168.4.1)
• Power: 5V USB-C / KCD11 Switch (~180mA draw)
• Storage: On-chip NVS flash (power-loss safe)
B. Industrial CAD Enclosure
• Envelope: 136.0 W × 145.0 L × 70.0 H mm
• Design: 2.5mm uniform walls, 48mm rear corner pillars
• Joint: 1.5mm stepped dust/light interlocking lap seam
• Fasteners: Unified 16x M3 heat-set brass threaded inserts
• Chassis Floor: Solid splash-proof base + 4x Ø12.5mm feet
• CAD Suite: Autodesk Inventor 2027 (.iam, .step, .stl)
